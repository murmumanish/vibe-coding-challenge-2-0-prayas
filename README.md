This is Sports Academy Website / App. Where Academy owner can add Coaches , Scouts, Sports, and Students.

## Getting Started

First Clone it:

```bash
git clone https://github.com/murmumanish/vibe-coding-challenge-2-0-prayas.git
```

Install Dependencies:

```bash
npm install .
```

Run the Server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
